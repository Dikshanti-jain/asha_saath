# Refresh a changing fact

Start with [source register](../../docs/RESEARCH_SOURCES.md), then inspect the relevant official guideline, ministry notice or vendor documentation. Prefer the current primary page over a search snippet or old manual.

Record publication/effective date, checked date, geography, applicable population and retrieval limits. Separate official descriptions from our design proposals and from local implementation assumptions.

If a current clinical schedule or live API contract cannot be verified, leave the rule inactive and visibly synthetic. Do not reuse a legacy HBNC/HBYC calendar as current SSBSK guidance.

Update [decisions](../../docs/DECISIONS.md) and affected spec/prompt files when a finding changes implementation. Never infer NGO partnership, government endorsement, platform certification or field impact from a directory listing or marketing page.
