# Build sequence and pilot roadmap

Version 1.0. The 24-hour schedule is a planning assumption from the earlier conversation; actual remaining time is not known. Compress/expand phases with the team while preserving the original PS core.

## 1. Hackathon sequence

| Time budget | Deliverable | Gate |
|---|---|---|
| 0–2h | Generate Lovable scaffold, load knowledge/specs, government shell, role views | Actual framework/config recorded; synthetic label, mobile shell work |
| 2–7h | CSV identity/validation, pure planner, grouping, route list, all unserved reasons | 24-task same-input plan is deterministic/feasible |
| 7–9h | Visit result, replan, coverage projection | Due dates immutable; no lost/duplicated projected tasks |
| 9–15h | Need/consent, three offers, provider views, backend transaction and role policies | Full scoped support flow; last-unit/duplicate checks |
| 15–18h | Delivery/confirmation/recovery, metrics | Provider report cannot close; unresolved owner visible |
| 18–21h | Hindi/mobile/accessibility; optional offline after working core | No hidden main action; offline labelled only if tested |
| 21–24h | Freeze, run core acceptance, rehearse success/failure and pitch | Recorded evidence, no overstated claims |

If time is short: simplify illustrations, skip external maps/voice/funding, keep visit optimizer plus one complete support journey. Do not spend the remaining hours importing 30 platform integrations.

## 2. Responsibilities for an all-round team

Assign clear owners for planner/data, UI/accessibility, referral/backend and demo/source verification. One person may hold multiple roles; avoid simultaneous editing of the same domain/state contract. Merge product decisions into DECISIONS and handoff rather than separate contradictory prompts.

## 3. First pilot hypothesis

One willing health catchment, an authorized health-team sponsor, a resourced coordinator, three to five participating providers and a small number of precise support categories. Validate rural and urban operation independently.

Before field use: approved data arrangement and clinical rules; consent language; provider participation/catchments/capacity; response escalation; resource/retention policy; actual phone/connectivity usability. No presumed access to government APIs.

Measure worker time, unresolved rates, capacity staleness, response time, confirmed support and recipient experience. Do not infer health outcomes from routing simulation.

## 4. Expansion sequence

1. Reliable service verification/refresh and coordinator recovery.
2. Additional nonclinical categories with their own eligibility/capacity/confirmation.
3. Approved integration with existing worker systems to reduce duplicate entry.
4. Joint-cadre scheduling only with authorized rules and calendars.
5. Restricted in-kind/funding approvals and reconciliation without custody.
6. State/national aggregate discovery/reporting with approved disclosure policy.

National scale is an operational network of participating offers and governance, not a larger search page.
