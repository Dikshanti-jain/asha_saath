The speech is approximately five minutes with short pauses at 125–135 words/minute; rehearse the three screen cues. [Word-count check](pitch-checks.json) and [browser visual review](mind-map-review.json) record actual artifact checks. A full interactive role journey needs a separate demonstration. Choose the document-referral or cash/message flow; doing both takes longer.

Download all these files together: [pitch kit ZIP](../../output/asha-saath-pitch-kit.zip). It also includes reviewed application screenshots and runtime verification notes; relative Markdown links are checked inside the archive.

Pitch centre: a workable ASHA day and a named person responsible until requested help is confirmed. The spoken workforce count is dated official context; NFHS-6 stays in supporting notes. The working synthetic extension adds NGO budget decisions, cash-assistance records, separate recipient confirmation and saved case messages/read receipts. Local demo counts/tests are software evidence. Actual funding/payments, real partner onboarding, pilot targets and benefits remain proposals until validated in the field.
